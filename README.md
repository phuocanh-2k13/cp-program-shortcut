# CP Program for Shortcut
_LINUX UBUNTU VERSION_

## Why I created this?
When I'm solving problems, I feel very uncomfortable to rewrite templates one by one. Create files at start, folder,...

So this program is target for people who is lazy, want to create a folder to contain their code in a second.

**Note:** This program is build in Linux Ubuntu, if you want on Windows or Macs, then clone the repo and build it yourself 

## How to use (install)
First, when you install the package, remember to unzip it.

Then, give permision to the installation script by using:
``` bash
chmod +x install.sh
```
_In case you don't trust install.sh, then go review it yourself_

After that, run this command:
``` bash
sudo ./install.sh
```

Then try run cp-setup, if it does appear something like, enter your problem name, the you're succes.
If not, try log out and log in back to your session.
